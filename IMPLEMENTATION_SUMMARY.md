# Итоговая сводка: Умный поиск файлов + Debug режим

## ✅ Что реализовано

### 1. Debug режим для Yandex.Disk API
**Файлы изменены:**
- `app/config.py` - добавлена настройка `yadisk_debug: bool = False`
- `app/services/yadisk_service.py` - добавлен метод `_log_api_call()`
- `.env.example` - добавлена переменная `YADISK_DEBUG=false`

**Как использовать:**
```env
# В .env добавьте:
YADISK_DEBUG=true
```

**Что логируется:**
- Все вызовы API Яндекс.Диска
- Параметры запросов
- Ответы API
- Ошибки

**Пример логов:**
```
[Yandex.Disk API] listdir | Params: {"path": "/", "depth": 0}
[Yandex.Disk API] Found file: Асия_Сценарий.pdf
[Yandex.Disk API] get_files_realtime | Response: Found 127 files
```

### 2. Реальный поиск через API
**Файлы изменены:**
- `app/services/yadisk_service.py` - добавлен метод `get_files_realtime()`

**Возможности:**
- Получение актуального списка файлов без кэша
- Рекурсивный обход всех папок
- Ограничение глубины (max_depth=10)
- Полная информация о файлах (имя, путь, тип, размер, ссылка)

**Использование:**
```python
files = await YandexDiskService.get_files_realtime(root_path="/")
# Возвращает: List[dict] с полями name, path, type, size, public_url
```

### 3. LLM-инструмент для умного поиска
**Файлы изменены:**
- `app/agent/tools.py` - добавлен инструмент `search_file_smart`

**Как работает:**
1. Получает список файлов через API (реальное время)
2. Отправляет список в LLM
3. LLM анализирует названия и выбирает релевантные
4. Возвращает отфильтрованный список с эмодзи и ссылками

**Примеры запросов:**
```
Найди файлы по фильму "Асия"
Покажи все сценарии
Найди видео со съемок
Покажи документы версии 2
```

### 4. Обновленный LLM-агент
**Файлы изменены:**
- `app/agent/llm_agent.py` - обновлен системный промпт

**Что добавлено:**
- Инструкции по выбору режима поиска
- Примеры использования обоих режимов
- Автоматический выбор между `search_file` и `search_file_smart`

**Логика выбора:**
- `search_file_smart` → для запросов типа "файлы по фильму X", "все сценарии"
- `search_file` → для точных названий "Горизонт_Сценарий.pdf"

## 📊 Сравнение режимов поиска

| Параметр | Обычный поиск | Умный поиск |
|----------|---------------|-------------|
| Источник | Кэш БД | API в реальном времени |
| Скорость | < 1 сек | 3-5 сек |
| Актуальность | Обновляется в 03:00 | Всегда актуально |
| Точность | Точное совпадение | Контекстный анализ |
| Стоимость | Бесплатно | ~$0.001-0.003 за запрос |

## ⚠️ Известные проблемы

### Telegram Conflict Error
```
TelegramConflictError: terminated by other getUpdates request
```

**Причина:** Другой экземпляр бота уже запущен где-то еще.

**Решение:**
1. Проверьте, нет ли других запущенных экземпляров
2. Подождите 1-2 минуты (Telegram автоматически отключит старый)
3. Или используйте другой токен бота для тестирования

### Медленный умный поиск

**Причина:** Много файлов на Диске (>500)

**Решение:**
1. Организуйте файлы в папки
2. Используйте обычный поиск для точных названий
3. Будущее обновление: кэширование результатов

## 📝 Рекомендации по использованию

### Организация файлов на Яндекс.Диске

Для лучшей работы умного поиска используйте понятные названия:

✅ **Хорошо:**
- `Асия_Сценарий_v2_финал.pdf`
- `Горизонт_Бэкстейдж_съемки_день1.mp4`
- `Асия_Презентация_инвесторы.pptx`

❌ **Плохо:**
- `doc123.pdf`
- `video.mp4`
- `новый_файл_копия_2.pdf`

### Когда использовать каждый режим

**Обычный поиск (`/find` или "найди файл X"):**
- Знаете точное название
- Нужен быстрый результат
- Файл в кэше

**Умный поиск ("найди файлы по фильму X"):**
- Поиск по проекту/фильму
- Нужны все файлы типа
- Файл только что добавлен
- Сложный контекстный запрос
