# Краткая инструкция: Работа в групповом чате

## 🚨 Текущая проблема

У бота включен **Privacy Mode** → бот не получает обычные сообщения в группе.

Проверка показала: `Can read all group messages: False`

## ✅ Быстрое решение

### Отключите Privacy Mode в BotFather:

1. Откройте [@BotFather](https://t.me/BotFather)
2. `/mybots` → выберите бота
3. **Bot Settings** → **Group Privacy** → **Turn off**
4. Готово! Перезапустите бота: `docker compose restart cinebot`

## 🎯 Что будет работать после отключения

- ✅ FSM диалоги в группе (`/addevent` → вводите название → дату → тип)
- ✅ LLM агент без упоминания ("Добавь событие завтра")
- ✅ Все функции как в ЛС

## 🔧 Временное решение (если не хотите отключать Privacy Mode)

### FSM диалоги:
- Используйте бота в **личных сообщениях** для `/addevent`
- В группе команда `/addevent` теперь покажет подсказку

### LLM агент:
- **Упоминайте бота** в сообщении:
  ```
  @CineCineTestBot добавь премьеру фильма Горизонт 20 апреля в 19:00
  ```

## 📊 Что изменилось в коде

Бот теперь:
1. Определяет, что работает в группе с Privacy Mode
2. Показывает понятное сообщение при попытке использовать `/addevent`
3. Обрабатывает упоминания бота в LLM агенте

## 🎯 Рекомендация

**Отключите Privacy Mode** — это корпоративный бот для вашей команды, все пользователи авторизованы через систему доступа, поэтому безопасность обеспечена middleware.

После отключения всё будет работать идеально! 🚀
