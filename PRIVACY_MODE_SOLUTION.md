# Решение проблемы Privacy Mode

## ✅ Что исправлено

### 1. Обработка `/addevent` в групповых чатах

Теперь при попытке использовать `/addevent` в группе с включенным Privacy Mode бот покажет понятное сообщение:

```
⚠️ FSM диалоги не работают в групповых чатах

У бота включен Privacy Mode, поэтому он не получает обычные сообщения в группе.

Варианты решения:
1️⃣ Напишите боту в личные сообщения для добавления события
2️⃣ Используйте естественный язык с упоминанием бота:
   @CineCineTestBot добавь премьеру фильма Горизонт 20 апреля в 19:00
3️⃣ Попросите администратора отключить Privacy Mode в @BotFather
```

### 2. LLM агент работает с упоминаниями

В групповых чатах с Privacy Mode:
- Бот обрабатывает сообщения с упоминанием `@CineCineTestBot`
- Автоматически убирает упоминание из текста перед обработкой
- Логирует обработку для отладки

### 3. Документация

Созданы файлы:
- `PRIVACY_MODE_FIX.md` — краткая инструкция по решению проблемы
- `GROUP_CHAT_SETUP.md` — подробная документация по работе в группах

## 🔧 Рекомендуемое решение

**Отключите Privacy Mode в BotFather:**

1. Откройте [@BotFather](https://t.me/BotFather)
2. `/mybots` → выберите бота
3. **Bot Settings** → **Group Privacy** → **Turn off**
4. Готово!

После этого:
- ✅ FSM диалоги будут работать в группе
- ✅ LLM агент будет работать без упоминания
- ✅ Всё будет работать как в ЛС
