# Триггерные слова для LLM-агента

## Что это такое?

Бот реагирует на обычные текстовые сообщения (не команды) **только если** в них есть одно из триггерных слов. Это позволяет боту работать в групповых чатах, не отвечая на каждое сообщение.

## Как это работает

1. Пользователь пишет сообщение в чат
2. Бот проверяет, есть ли в сообщении триггерное слово
3. Если есть — передаёт сообщение LLM-агенту для обработки
4. Если нет — игнорирует сообщение

## Полный список триггерных слов

Текущий список настраивается через переменную окружения `LLM_TRIGGER_WORDS` в `.env`:

### Действия с событиями
- **добавить** / **добавь** — добавление нового события
- **создать** / **создай** — создание события
- **запланировать** / **запланируй** — планирование события
- **удалить** / **удали** — удаление события
- **отменить** / **отмени** — отмена события

### Поиск и просмотр
- **найти** / **найди** — поиск файлов на Яндекс.Диске
- **искать** / **ищи** — поиск файлов
- **покажи** / **покажите** — показать события или файлы
- **список** — показать список событий
- **события** — показать события

## Примеры использования

### ✅ Сработает (есть триггерное слово)

```
Добавь премьеру фильма ФИЛЬМ 20 апреля в 19:00
```
Триггер: **добавь**

```
Найди сценарий фильма Асия
```
Триггер: **найди**

```
Покажи ближайшие события
```
Триггер: **покажи**

```
Удали событие 5
```
Триггер: **удали**

### ❌ Не сработает (нет триггерного слова)

```
Привет, как дела?
```
Нет триггерных слов — бот проигнорирует

```
Когда премьера?
```
Нет триггерных слов — бот проигнорирует

```
Спасибо!
```
Нет триггерных слов — бот проигнорирует

## Работа в групповых чатах

**Важно:** В групповых чатах бот работает **БЕЗ упоминания** (@BotName не нужен)!

Достаточно написать сообщение с триггерным словом:

```
Найди сценарий Асия
```

Вместо:

```
@CineBot найди сценарий Асия
```

## Настройка триггерных слов

Чтобы изменить список триггерных слов:

1. Откройте файл `.env`
2. Найдите строку `LLM_TRIGGER_WORDS`
3. Добавьте или удалите слова через запятую:

```env
LLM_TRIGGER_WORDS=добавить,добавь,найти,найди,покажи,покажите,удалить,удали,создать,создай,запланировать,запланируй,искать,ищи,отменить,отмени,список,события
```

4. Перезапустите бота:

```bash
docker compose restart cinebot
```

## Технические детали

### Регистр

Проверка триггерных слов **не зависит от регистра**:
- `Добавь` = `добавь` = `ДОБАВЬ`

### Частичное совпадение

Триггерное слово может быть частью другого слова:
- `добавить` найдётся в `"Нужно добавить событие"`
- `найди` найдётся в `"Найдите файл"`

### Несколько триггеров

Если в сообщении несколько триггерных слов — бот всё равно обработает его один раз:
- `"Найди и добавь событие"` — сработает (есть `найди` и `добавь`)

## Отключение фильтрации

Если вы хотите, чтобы бот реагировал на **все** сообщения (не рекомендуется для групповых чатов):

1. Оставьте `LLM_TRIGGER_WORDS` пустым в `.env`:

```env
LLM_TRIGGER_WORDS=
```

2. Перезапустите бота

**Внимание:** В этом режиме бот будет отвечать на каждое сообщение в группе, что может быть навязчиво.

## Логирование

Бот логирует информацию о триггерных словах:

```
DEBUG | No trigger words found in message: Привет, как дела?...
INFO  | Processing group message with trigger word: Найди сценарий...
```

Чтобы увидеть эти логи:

```bash
docker compose logs cinebot -f
```

## FAQ

### Почему бот не отвечает на мои сообщения?

1. Проверьте, что в сообщении есть триггерное слово
2. Проверьте, что LLM-агент включён (есть `OPENROUTER_API_KEY` в `.env`)
3. Проверьте логи: `docker compose logs cinebot -f`

### Можно ли добавить свои триггерные слова?

Да! Просто добавьте их в `LLM_TRIGGER_WORDS` через запятую и перезапустите бота.

### Работает ли это в личных сообщениях?

Да, в личных сообщениях бот также проверяет триггерные слова. Если вы хотите, чтобы в личных сообщениях бот отвечал на всё, используйте команды (`/addevent`, `/find` и т.д.) вместо естественного языка.

### Как бот понимает, что делать с сообщением?

После того как бот определил, что в сообщении есть триггерное слово, он передаёт **весь текст** LLM-агенту (OpenRouter API), который анализирует намерение и выполняет соответствующее действие.
