# Фильтрация сообщений для LLM-агента

## Что изменилось

Теперь LLM-агент реагирует **только на сообщения с триггерными словами**, а не на все текстовые сообщения.

## Триггерные слова

По умолчанию бот реагирует на следующие слова:

### Для добавления событий:
- добавить, добавь
- создать, создай
- запланировать, запланируй

### Для поиска файлов:
- найти, найди
- искать, ищи
- покажи, покажите

### Для удаления:
- удалить, удали
- отменить, отмени

### Для просмотра:
- список
- события

## Примеры использования

### ✅ Бот ответит:
```
Добавь премьеру фильма Горизонт 20 апреля в 19:00
Найди сценарий Асия
Покажи ближайшие события
Удали событие 5
```

### ❌ Бот проигнорирует:
```
Привет, как дела?
Что думаешь о погоде?
Спасибо за помощь!
```

## Работа в групповом чате

**Важно:** В групповом чате бот работает **БЕЗ упоминаний**!

### ✅ Правильно (в группе):
```
Добавь премьеру фильма Асия 25 марта
```

### ❌ Не нужно (упоминание не требуется):
```
@CineCineTestBot добавь премьеру фильма Асия 25 марта
```

## Настройка триггерных слов

Вы можете настроить список триггерных слов через `.env`:

```env
LLM_TRIGGER_WORDS=добавить,добавь,найти,найди,покажи,удалить,удали,создать,запланируй
```

**Формат:** слова через запятую, без пробелов.

## Целевой групповой чат

Если указан `GROUP_CHAT_ID` в `.env`, бот будет работать только в этом чате:

```env
GROUP_CHAT_ID=-1001234567890
```

Если `GROUP_CHAT_ID` не указан, бот будет работать во всех групповых чатах (где он добавлен).

## Преимущества фильтрации

1. **Не мешает обычному общению** - бот не реагирует на обычную переписку в группе
2. **Экономия токенов** - LLM не обрабатывает ненужные сообщения
3. **Быстрее работает** - меньше запросов к API
4. **Понятнее для пользователей** - четкие триггерные слова

## Отладка

Если бот не реагирует на ваши сообщения:

1. **Проверьте триггерные слова:**
   ```bash
   docker compose logs cinebot | grep "No trigger words"
   ```

2. **Проверьте ID чата:**
   ```bash
   docker compose logs cinebot | grep "non-target group"
   ```

3. **Проверьте, что LLM-агент доступен:**
   ```bash
   docker compose logs cinebot | grep "LLM agent"
   ```

## Логи

При включенном debug режиме вы увидите:

```
[DEBUG] No trigger words found in message: Привет, как дела?...
[INFO] Processing group message with trigger word: Добавь премьеру...
```

## Миграция

Если у вас уже был запущен бот:

1. Добавьте в `.env` (опционально):
   ```env
   LLM_TRIGGER_WORDS=добавить,добавь,найти,найди,покажи,удалить,удали
   ```

2. Перезапустите бота:
   ```bash
   docker compose restart cinebot
   ```

3. Готово! Бот теперь реагирует только на триггерные слова.

## Часто задаваемые вопросы

### Можно ли добавить свои триггерные слова?

Да, через `.env`:
```env
LLM_TRIGGER_WORDS=добавить,найти,покажи,мой_триггер
```

### Регистр имеет значение?

Нет, все слова проверяются в нижнем регистре. "Добавить", "добавить", "ДОБАВИТЬ" - все работает.

### Можно ли отключить фильтрацию?

Да, установите пустой список:
```env
LLM_TRIGGER_WORDS=
```

Тогда бот будет реагировать на все сообщения (как раньше).

### Работает ли в личных сообщениях?

Да, фильтрация работает везде - и в группах, и в личных сообщениях.

### Нужно ли упоминать бота в группе?

Нет! Бот работает без упоминаний, достаточно использовать триггерное слово.
