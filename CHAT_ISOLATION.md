# Изоляция чатов в CineBot

## Обзор

Бот теперь полностью поддерживает работу как в личных сообщениях (ЛС), так и в групповых чатах с изоляцией данных между чатами.

## Реализованная изоляция

### 1. Команды бота

#### `/addevent` - Добавление события
- ✅ Сохраняет `chat_id` при создании события
- ✅ Работает в ЛС и группах
- ✅ События привязаны к конкретному чату

#### `/events` - Просмотр событий
- ✅ Показывает только события текущего чата
- ✅ Фильтрация по `message.chat.id`
- ✅ Изолированный просмотр для каждого чата

#### `/delevent` - Удаление события
- ✅ Показывает только события текущего чата
- ✅ Проверяет принадлежность события перед удалением
- ✅ Защита от удаления чужих событий

#### `/find` - Поиск файлов
- ✅ Работает одинаково во всех чатах
- ℹ️ Яндекс.Диск общий для всех (по дизайну)

#### `/help`, `/start`, `/cancel`
- ✅ Информационные команды, работают везде

### 2. LLM-агент (естественный язык)

#### Обработка сообщений
- ✅ Получает `chat_id` из `message.chat.id`
- ✅ Передает `chat_id` всем инструментам
- ✅ Автоматически добавляет `chat_id` если отсутствует

#### Инструменты агента

**`add_event`** - Добавить событие
- ✅ Принимает параметр `chat_id`
- ✅ Сохраняет событие с привязкой к чату
- Пример: "Добавь премьеру 20 апреля в 19:00"

**`list_events`** - Показать события
- ✅ Принимает параметр `chat_id`
- ✅ Фильтрует события по чату
- Пример: "Покажи ближайшие события"

**`delete_event`** - Удалить событие
- ✅ Принимает параметр `chat_id`
- ✅ Проверяет права доступа
- ✅ Защита от удаления чужих событий
- Пример: "Удали событие 5"

**`search_file`** - Найти файл
- ✅ Работает одинаково во всех чатах
- ℹ️ Яндекс.Диск общий (по дизайну)
- Пример: "Найди сценарий Горизонт"

## Сценарии использования

### Личные сообщения (ЛС)
```
Пользователь → Бот (ЛС)
- Добавляет события через команды или LLM
- Видит только свои события
- Управляет только своими событиями
```

### Групповой чат
```
Группа → Бот (в группе)
- Все участники видят события группы
- Любой участник может добавлять события
- События изолированы от других групп и ЛС
```

### Несколько чатов
```
Пользователь в ЛС: события A, B, C
Группа 1: события D, E
Группа 2: события F, G

Каждый чат видит только свои события!
```

## Безопасность

✅ **Изоляция данных**: События одного чата не видны в другом
✅ **Защита от удаления**: Нельзя удалить событие из другого чата
✅ **Проверка прав**: Все операции проверяют `chat_id`
✅ **Работает везде**: Команды и LLM-агент используют одну логику
