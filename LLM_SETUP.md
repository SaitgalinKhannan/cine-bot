# Настройка LLM-агента

## Что такое LLM-агент?

LLM-агент позволяет общаться с ботом на естественном русском языке вместо использования команд.

**Без LLM:**
```
/addevent
[пошаговый диалог]
```

**С LLM:**
```
Добавь премьеру фильма Горизонт 20 апреля в 19:00
```

## Получение API ключа OpenRouter

### Шаг 1: Регистрация

1. Перейдите на [OpenRouter.ai](https://openrouter.ai/)
2. Нажмите "Sign In" и зарегистрируйтесь
3. Подтвердите email

### Шаг 2: Получение API ключа

1. Откройте [Keys](https://openrouter.ai/keys)
2. Нажмите "Create Key"
3. Скопируйте ключ (начинается с `sk-or-v1-`)

### Шаг 3: Добавление в .env

Откройте `.env` и добавьте:

```env
OPENROUTER_API_KEY=sk-or-v1-ваш_ключ_здесь
LLM_MODEL=openrouter/hunter-alpha
LLM_BASE_URL=https://openrouter.ai/api/v1
```

### Шаг 4: Перезапуск бота

```bash
docker compose restart bot
```

Проверьте логи:
```bash
docker compose logs bot | grep "LLM agent"
```

Должно быть:
```
LLM agent enabled with model: openrouter/hunter-alpha
```

## Доступные модели

### Рекомендуемые

1. **openrouter/hunter-alpha** (по умолчанию)
   - Быстрая и точная
   - Хорошо понимает русский язык
   - Платная, но недорогая

2. **qwen/qwen3-next-80b-a3b-instruct:free**
   - Бесплатная
   - Хорошее качество
   - Может быть медленнее

3. **minimax/minimax-m2.5:free**
   - Бесплатная альтернатива
   - Хорошо работает с русским

4. **openrouter/healer-alpha**
   - Альтернативная платная модель
   - Хорошая точность

### Смена модели

В `.env`:
```env
LLM_MODEL=qwen/qwen3-next-80b-a3b-instruct:free
```

Перезапустите бота:
```bash
docker compose restart bot
```

## Стоимость

### Бесплатные модели
- `qwen/qwen3-next-80b-a3b-instruct:free` - полностью бесплатно
- `minimax/minimax-m2.5:free` - полностью бесплатно

### Платные модели
- `openrouter/hunter-alpha` - ~$0.001 за запрос
- `openrouter/healer-alpha` - ~$0.001 за запрос

Проверить баланс: [OpenRouter Credits](https://openrouter.ai/credits)

## Работа без LLM-агента

Бот полностью функционален без LLM-агента!

Если `OPENROUTER_API_KEY` не настроен:
- Все команды работают как обычно
- Используйте `/addevent`, `/events`, `/find` и т.д.
- Пошаговые диалоги доступны

## Проверка работы

### Тест 1: Проверка инициализации

```bash
docker compose logs bot | grep "LLM"
```

Ожидаемый вывод:
```
LLM agent initialized with model: openrouter/hunter-alpha
LLM agent enabled with model: openrouter/hunter-alpha
```

### Тест 2: Отправка сообщения

Напишите боту в Telegram:
```
Покажи ближайшие события
```

Бот должен ответить списком событий (или сообщением, что событий нет).

### Тест 3: Добавление события

```
Добавь встречу с режиссёром 25 марта в 15:00
```

Бот должен создать событие и подтвердить.

## Troubleshooting

### Ошибка: "LLM agent not available"

**Причина:** API ключ не настроен или неверный

**Решение:**
1. Проверьте `.env`:
   ```bash
   cat .env | grep OPENROUTER
   ```
2. Убедитесь, что ключ начинается с `sk-or-v1-`
3. Перезапустите бота:
   ```bash
   docker compose restart bot
   ```

### Ошибка: "Invalid API key"

**Причина:** Неверный или истёкший ключ

**Решение:**
1. Создайте новый ключ на [OpenRouter](https://openrouter.ai/keys)
2. Обновите `.env`
3. Перезапустите бота

### Бот не отвечает на естественный язык

**Причина:** LLM handler не зарегистрирован или агент не инициализирован

**Решение:**
1. Проверьте логи:
   ```bash
   docker compose logs bot | tail -50
   ```
2. Убедитесь, что нет ошибок при инициализации
3. Попробуйте команды вместо естественного языка

### Медленные ответы

**Причина:** Модель медленная или перегружена

**Решение:**
1. Попробуйте другую модель:
   ```env
   LLM_MODEL=openrouter/hunter-alpha
   ```
2. Используйте команды для быстрого доступа

### Неправильное понимание запросов

**Причина:** Модель неправильно интерпретирует намерение

**Решение:**
1. Формулируйте запросы чётче:
   - ❌ "Добавь что-то на завтра"
   - ✅ "Добавь встречу 17 марта в 14:00"
2. Используйте команды для точного контроля
3. Попробуйте другую модель

## Логирование

LLM-агент логирует все запросы:

```bash
docker compose logs bot | grep "LLM"
```

Примеры логов:
```
Processing message with LLM: Добавь премьеру...
LLM response: ✅ Событие добавлено!...
```

## Отключение LLM-агента

Чтобы отключить LLM и использовать только команды:

1. Удалите или закомментируйте в `.env`:
   ```env
   # OPENROUTER_API_KEY=...
   ```

2. Перезапустите бота:
   ```bash
   docker compose restart bot
   ```

Бот будет работать только через команды.

## Безопасность

- API ключ хранится в `.env` (не коммитится в git)
- Ключ передаётся только в OpenRouter API
- Сообщения пользователей не сохраняются
- История диалогов не ведётся
