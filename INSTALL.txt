📋 БЫСТРАЯ УСТАНОВКА (5 минут)

1️⃣  Получить токены:
   • Telegram Bot Token: https://t.me/BotFather
   • Group Chat ID: добавить бота в группу, написать сообщение,
     открыть https://api.telegram.org/bot<TOKEN>/getUpdates
   • Yandex.Disk Token: https://oauth.yandex.ru/

2️⃣  Настроить .env:
   cp .env.example .env
   nano .env
   # Заполнить BOT_TOKEN, GROUP_CHAT_ID, YANDEX_DISK_TOKEN

3️⃣  Проверить готовность:
   ./check_setup.sh

4️⃣  Запустить:
   docker compose up -d

5️⃣  Проверить логи:
   docker compose logs -f bot

✅ Готово! Бот работает.

🔧 УПРАВЛЕНИЕ

Через скрипт:
  ./bot.sh start        # Запустить
  ./bot.sh stop         # Остановить
  ./bot.sh logs         # Логи
  ./bot.sh status       # Статус

Через Makefile:
  make start            # Запустить
  make stop             # Остановить
  make logs             # Логи

Через Docker Compose:
  docker compose up -d              # Запустить
  docker compose down               # Остановить
  docker compose logs -f bot        # Логи
