# Changelog: Умный поиск файлов

## [1.1.0] - 2026-03-20

### Добавлено

#### Умный поиск файлов через LLM
- Новый инструмент `search_file_smart` для поиска файлов через естественный язык
- LLM анализирует названия файлов и выбирает релевантные
- Получение актуального списка файлов через API Яндекс.Диска (без кэша)
- Поддержка сложных запросов: "найди файлы по фильму X", "покажи все сценарии"

#### Debug режим для Yandex.Disk API
- Новая настройка `YADISK_DEBUG` в `.env`
- Логирование всех запросов к API Яндекс.Диска
- Логирование ответов и ошибок API
- Помогает отладить проблемы с доступом к файлам

#### Новые методы в YandexDiskService
- `get_files_realtime()` - получение списка файлов в реальном времени
- `_log_api_call()` - логирование вызовов API
- Рекурсивный обход всех папок на Диске
- Ограничение глубины рекурсии (max_depth=10)

### Производительность

#### Обычный поиск (search_file)
- Скорость: < 1 секунда
- Источник: кэш базы данных
- Актуальность: обновляется в 03:00

#### Умный поиск (search_file_smart)
- Скорость: 3-5 секунд
- Источник: API Яндекс.Диска + LLM
- Актуальность: всегда актуально
- Стоимость: ~500-1000 токенов на запрос

### Ограничения

- Максимум 500 файлов для анализа LLM
- Максимальная глубина рекурсии: 10 уровней
- Лимит результатов: 10 файлов по умолчанию

### Примеры использования

#### До (обычный поиск)
```
Пользователь: /find Асия
Бот: Ищет точное совпадение "Асия" в названии
```

#### После (умный поиск)
```
Пользователь: Найди файлы по фильму "Асия"
Бот: Находит все файлы, связанные с фильмом:
     - Асия_Сценарий_финал.pdf
     - Асия_Трейлер_v2.mp4
     - Асия_Постер_главный.jpg
     - Асия_Презентация_инвесторы.pptx
     - Асия_Бэкстейдж_съемки.mp4
```

### Миграция

Никаких действий не требуется. Старый поиск продолжает работать.

Для включения debug режима добавьте в `.env`:
```env
YADISK_DEBUG=true
```

### Известные проблемы

- При большом количестве файлов (>1000) умный поиск может быть медленным
- LLM может неправильно интерпретировать запрос (решается улучшением промпта)
