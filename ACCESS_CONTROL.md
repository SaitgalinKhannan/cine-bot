# Система контроля доступа CineBot

## Обзор

Бот теперь имеет систему контроля доступа на основе сотрудников и администраторов. Только авторизованные пользователи могут использовать бота.

## Роли пользователей

### Администратор (admin)
- Полный доступ ко всем функциям бота
- Может добавлять и удалять сотрудников
- Может просматривать список всех пользователей
- Автоматически создается при первом обращении, если его Telegram ID указан в `ADMIN_TELEGRAM_IDS`

### Сотрудник (employee)
- Доступ ко всем основным функциям бота
- Может добавлять, просматривать и удалять события
- Может искать файлы на Яндекс.Диске
- Не может управлять другими пользователями

## Настройка

### 1. Добавление администраторов

В файле `.env` укажите Telegram ID администраторов через запятую:

```env
ADMIN_TELEGRAM_IDS=123456789,987654321
```

**Как узнать свой Telegram ID:**
1. Напишите боту [@userinfobot](https://t.me/userinfobot)
2. Он отправит вам ваш ID

### 2. Первый запуск

При первом обращении к боту:
- Если ваш Telegram ID указан в `ADMIN_TELEGRAM_IDS`, вы автоматически станете администратором
- Если нет — получите сообщение "Доступ запрещен"

## Команды администратора

### /addemployee
Добавить нового сотрудника.

**Использование:**
1. Попросите нового сотрудника написать любое сообщение боту или в чат с ботом
2. Ответьте на его сообщение командой `/addemployee`
3. Сотрудник будет добавлен и получит доступ к боту

**Пример:**
```
Новый сотрудник: Привет!
Админ: /addemployee (reply на сообщение выше)
Бот: ✅ Сотрудник добавлен!
```

### /removeemployee
Удалить сотрудника (деактивировать доступ).

**Использование:**
1. Ответьте на сообщение сотрудника командой `/removeemployee`
2. Сотрудник будет деактивирован и потеряет доступ к боту

**Ограничения:**
- Нельзя удалить администратора
- Нельзя удалить самого себя

### /listemployees
Показать список всех пользователей (администраторов и сотрудников).

**Пример вывода:**
```
👥 Список сотрудников

👑 Администраторы:
✅ Иван Иванов (@ivan)
✅ Мария Петрова (@maria)

👤 Сотрудники:
✅ Алексей Сидоров (@alex)
❌ Ольга Смирнова (@olga) [деактивирован]

Всего: 4 чел.
```

## Работа системы

### Авторизация

При каждом сообщении боту:
1. Middleware проверяет, авторизован ли пользователь
2. Если пользователь в списке администраторов (`.env`) — автоматически создается как админ
3. Если пользователь не найден в БД — отклоняется с сообщением "Доступ запрещен"
4. Если пользователь деактивирован — отклоняется

### Исключения

Команда `/start` доступна всем пользователям (для приветствия).

## События и данные

**Важно:** События и файлы теперь **глобальные** для всех авторизованных пользователей:
- Все сотрудники видят все события
- Любой сотрудник может удалить любое событие
- Поиск файлов работает одинаково для всех

Это сделано по дизайну для корпоративного использования, где вся команда работает с общими данными.

## База данных

### Таблица users

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    telegram_id BIGINT UNIQUE NOT NULL,
    username VARCHAR(255),
    full_name VARCHAR(255),
    role VARCHAR(50) NOT NULL DEFAULT 'employee',
    is_active BOOLEAN NOT NULL DEFAULT true,
    created_at TIMESTAMP NOT NULL DEFAULT now()
);
```

### Поля:
- `telegram_id` — уникальный ID пользователя в Telegram
- `username` — @username (может быть NULL)
- `full_name` — полное имя пользователя
- `role` — роль: "admin" или "employee"
- `is_active` — активен ли пользователь (для мягкого удаления)

## Безопасность

✅ **Реализовано:**
- Middleware проверяет авторизацию перед каждым запросом
- Администраторы задаются через переменные окружения
- Команды администратора доступны только администраторам
- Нельзя удалить администратора через `/removeemployee`
- Нельзя удалить самого себя

⚠️ **Рекомендации:**
- Храните `.env` в безопасности (не коммитьте в Git)
- Регулярно проверяйте список сотрудников через `/listemployees`
- При увольнении сотрудника сразу используйте `/removeemployee`

## Примеры использования

### Сценарий 1: Добавление первого администратора

1. Узнайте свой Telegram ID через [@userinfobot](https://t.me/userinfobot)
2. Добавьте в `.env`: `ADMIN_TELEGRAM_IDS=123456789`
3. Перезапустите бота: `docker compose restart cinebot`
4. Напишите боту `/start` — вы автоматически станете администратором

### Сценарий 2: Добавление нового сотрудника

1. Новый сотрудник пишет боту: "Привет"
2. Бот отвечает: "🚫 Доступ запрещен"
3. Администратор отвечает на сообщение сотрудника: `/addemployee`
4. Бот: "✅ Сотрудник добавлен!"
5. Теперь сотрудник может пользоваться ботом

### Сценарий 3: Удаление сотрудника

1. Администратор отвечает на любое сообщение сотрудника: `/removeemployee`
2. Бот: "✅ Сотрудник удален"
3. Сотрудник больше не может пользоваться ботом

- Они доступны всем авторизованным пользователям
- Ничего не нужно мигрировать

## Troubleshooting

### Проблема: "Доступ запрещен" для администратора

**Решение:**
1. Проверьте, что ваш Telegram ID правильно указан в `.env`
2. Перезапустите бота: `docker compose restart cinebot`
3. Напишите боту `/start`

### Проблема: Команды администратора не работают

**Решение:**
1. Проверьте свою роль: `/listemployees`
2. Убедитесь, что вы в списке администраторов
3. Проверьте логи: `docker compose logs cinebot --tail=50`

### Проблема: Сотрудник не может быть добавлен

**Решение:**
1. Убедитесь, что вы отвечаете на сообщение сотрудника (reply)
2. Проверьте, что вы администратор
3. Проверьте логи на наличие ошибок
