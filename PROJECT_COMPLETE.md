## 🚀 Как запустить

### Вариант 1: Быстрый старт (5 минут)

```bash
# 1. Настроить .env
cp .env.example .env
nano .env  # Заполнить токены

# 2. Проверить готовность
./check_setup.sh

# 3. Запустить
docker compose up -d

# 4. Проверить логи
docker compose logs -f bot
```

### Вариант 2: Через скрипт

```bash
./bot.sh start    # Запустить
./bot.sh logs     # Посмотреть логи
./bot.sh status   # Проверить статус
```

### Вариант 3: Через Makefile

```bash
make start        # Запустить
make logs         # Посмотреть логи
make check        # Проверить готовность
```
