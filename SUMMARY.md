## 🚀 Быстрый старт

### 1. Настройка окружения

```bash
# Клонировать репозиторий
git clone <repository-url>
cd cine-bot

# Настроить .env
cp .env.example .env
nano .env  # Заполнить реальными токенами
```

### 2. Получение токенов

**Telegram Bot Token:**
1. Написать [@BotFather](https://t.me/BotFather)
2. Создать бота: `/newbot`
3. Скопировать токен

**Group Chat ID:**
1. Добавить бота в группу
2. Написать в группе
3. Открыть: `https://api.telegram.org/bot<TOKEN>/getUpdates`
4. Найти `"chat":{"id":-1001234567890}`

**Yandex.Disk Token:**
1. [OAuth Яндекса](https://oauth.yandex.ru/)
2. Зарегистрировать приложение
3. Получить токен с правами на чтение

### 3. Запуск

```bash
# Проверить готовность
./check_setup.sh

# Запустить
docker compose up -d

# Проверить логи
docker compose logs -f bot

# Или использовать скрипт
./bot.sh start
./bot.sh logs
```

## 🔧 Управление ботом

### Через скрипт bot.sh
```bash
./bot.sh start      # Запустить
./bot.sh stop       # Остановить
./bot.sh restart    # Перезапустить
./bot.sh logs       # Показать логи
./bot.sh status     # Статус сервисов
./bot.sh db         # Подключиться к PostgreSQL
./bot.sh migrate    # Применить миграции
```

### Через Makefile
```bash
make start          # Запустить
make stop           # Остановить
make logs           # Показать логи
make check          # Проверить готовность
```

### Через Docker Compose
```bash
docker compose up -d              # Запустить
docker compose down               # Остановить
docker compose logs -f bot        # Логи
docker compose ps                 # Статус
docker compose restart bot        # Перезапустить
```

## 🗄️ База данных

### Таблица events
- id, title, event_type, event_date
- description, chat_id, remind_days
- is_notified, created_at

### Таблица yandex_files_cache
- id, file_name, file_path
- public_url, file_type, updated_at

### Миграции
```bash
# Применить миграции
docker compose exec bot alembic upgrade head

# Откатить
docker compose exec bot alembic downgrade -1

# История
docker compose exec bot alembic history
```
