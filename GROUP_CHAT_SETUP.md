# Работа бота в групповых чатах

## ⚠️ Важно: Privacy Mode

По умолчанию Telegram боты в групповых чатах работают в режиме приватности (Privacy Mode). В этом режиме бот **не получает** обычные текстовые сообщения.

### Что бот получает в Privacy Mode:
- ✅ Команды: `/addevent`, `/events`, `/help`
- ✅ Сообщения с упоминанием: `@CineCineTestBot привет`
- ✅ Ответы (reply) на сообщения бота

### Что бот НЕ получает:
- ❌ Обычные текстовые сообщения
- ❌ Ответы в FSM диалогах (название события, дата и т.д.)
- ❌ Сообщения для LLM агента без упоминания бота

## 🔧 Решение: Отключить Privacy Mode

### Вариант 1: Отключить через BotFather (рекомендуется)

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/mybots`
3. Выберите вашего бота (CineCineTestBot)
4. Нажмите **Bot Settings**
5. Нажмите **Group Privacy**
6. Нажмите **Turn off** (Выключить)
7. Готово! Теперь бот получает все сообщения в группе

### Вариант 2: Использовать бота в личных сообщениях

Если вы хотите оставить Privacy Mode включенным:
- FSM диалоги (добавление событий) работают только в ЛС с ботом
- В группе используйте только команды просмотра: `/events`, `/find`
- Для добавления событий переходите в ЛС с ботом

## 📱 Рекомендации по использованию

### Для корпоративного использования (рекомендуется):

**Отключите Privacy Mode**, чтобы:
- ✅ FSM диалоги работали в группе
- ✅ LLM агент понимал обычные сообщения
- ✅ Можно было писать "Добавь событие..." без команд
- ✅ Удобнее для всей команды

**Безопасность:**
- Бот видит все сообщения в группе, но обрабатывает только от авторизованных пользователей
- Middleware проверяет права доступа перед обработкой
- Неавторизованные пользователи получают "Доступ запрещен"

### Для приватного использования:

**Оставьте Privacy Mode включенным**, если:
- Группа используется для разных целей
- Не хотите, чтобы бот "видел" все сообщения
- Готовы использовать бота в ЛС для FSM диалогов

## 🎯 Как работает бот в разных режимах

### С Privacy Mode OFF (рекомендуется для CineBot):

```
Группа:
Пользователь: /addevent
Бот: Введите название события
Пользователь: Премьера фильма Горизонт
Бот: Введите дату... ✅ РАБОТАЕТ

Пользователь: Добавь событие на завтра
Бот: [LLM обрабатывает и добавляет] ✅ РАБОТАЕТ
```

### С Privacy Mode ON (по умолчанию):

```
Группа:
Пользователь: /addevent
Бот: Введите название события
Пользователь: Премьера фильма Горизонт
Бот: [не получает сообщение] ❌ НЕ РАБОТАЕТ

Пользователь: Добавь событие на завтра
Бот: [не получает сообщение] ❌ НЕ РАБОТАЕТ

Решение: Использовать в ЛС или отключить Privacy Mode
```

## 🔍 Проверка текущего режима

Чтобы проверить, включен ли Privacy Mode:

1. Напишите в группе обычное сообщение (не команду)
2. Проверьте логи бота:
```bash
docker compose logs cinebot --tail=50
```

Если в логах нет вашего сообщения → Privacy Mode включен
Если в логах есть ваше сообщение → Privacy Mode выключен

## 📋 Пошаговая инструкция для группового чата

### Шаг 1: Отключите Privacy Mode (см. выше)

### Шаг 2: Добавьте бота в группу

1. Откройте групповой чат
2. Нажмите на название группы → Добавить участников
3. Найдите вашего бота и добавьте
4. Дайте боту права администратора (опционально, но рекомендуется)

### Шаг 3: Проверьте работу

В группе:
```
/start - проверка доступа
/help - список команд
/addevent - добавление события (FSM диалог)
Добавь премьеру завтра - через LLM агента
```

## ⚙️ Альтернативное решение: Inline-режим

Если не хотите отключать Privacy Mode, можно добавить inline-режим:

```
@CineCineTestBot добавь событие Премьера 20.04.2026 19:00
```

Но это требует дополнительной разработки.

## 📊 Сравнение режимов

| Функция | Privacy ON | Privacy OFF |
|---------|-----------|-------------|
| Команды в группе | ✅ | ✅ |
| FSM диалоги в группе | ❌ | ✅ |
| LLM агент в группе | ❌ | ✅ |
| FSM диалоги в ЛС | ✅ | ✅ |
| LLM агент в ЛС | ✅ | ✅ |
| Безопасность | Бот не видит сообщения | Middleware проверяет права |

## 🎯 Рекомендация для CineBot

**Отключите Privacy Mode** через BotFather, потому что:
1. CineBot — корпоративный бот для команды
2. Все пользователи авторизованы через систему доступа
3. FSM диалоги и LLM агент должны работать в группе
4. Middleware защищает от несанкционированного доступа

После отключения Privacy Mode всё будет работать как ожидается! 🚀
