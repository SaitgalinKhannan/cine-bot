# CineBot - Быстрый старт с системой доступа

## 🚀 Запуск бота с контролем доступа

### Шаг 1: Узнайте свой Telegram ID

Напишите боту [@userinfobot](https://t.me/userinfobot) в Telegram, он отправит вам ваш ID (например: `123456789`)

### Шаг 2: Добавьте себя как администратора

Откройте файл `.env` и найдите строку:

```env
# Admin users (comma-separated telegram IDs)
ADMIN_TELEGRAM_IDS=
```

Добавьте свой Telegram ID:

```env
ADMIN_TELEGRAM_IDS=123456789
```

Если администраторов несколько, укажите через запятую:

```env
ADMIN_TELEGRAM_IDS=123456789,987654321
```

### Шаг 3: Перезапустите бота

```bash
docker compose restart cinebot
```

### Шаг 4: Проверьте доступ

Напишите боту в Telegram:

```
/start
```

Если всё настроено правильно:
- ✅ Вы получите приветственное сообщение
- ✅ Вы автоматически станете администратором
- ✅ Все команды будут доступны

Если вы не добавили свой ID в `.env`:
- ❌ Получите сообщение "🚫 Доступ запрещен"

## 📋 Добавление сотрудников

### Вариант 1: Через reply (рекомендуется)

1. Попросите нового сотрудника написать боту любое сообщение
2. Ответьте (reply) на его сообщение командой `/addemployee`
3. Готово! Сотрудник получит доступ

### Вариант 2: В групповом чате

1. Добавьте бота в групповой чат
2. Новый сотрудник пишет в чат
3. Вы отвечаете на его сообщение: `/addemployee`
4. Сотрудник получает доступ к боту

## 🔧 Команды администратора

```
/addemployee — Добавить сотрудника (reply на его сообщение)
/removeemployee — Удалить сотрудника (reply на его сообщение)
/listemployees — Показать всех пользователей
```

## 📊 Структура базы данных

Добавлена таблица `users`:

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    telegram_id BIGINT UNIQUE NOT NULL,
    username VARCHAR(255),
    full_name VARCHAR(255),
    role VARCHAR(50) NOT NULL DEFAULT 'employee',
    is_active BOOLEAN NOT NULL DEFAULT true,
    created_at TIMESTAMP NOT NULL DEFAULT now()
);
```

## 🔒 Безопасность

- Команда `/start` доступна всем (для приветствия)
- Все остальные команды требуют авторизации
- Администраторы задаются через переменные окружения
- Нельзя удалить администратора через `/removeemployee`
- Нельзя удалить самого себя

## 📝 Важные изменения

### События теперь глобальные

- Все авторизованные пользователи видят все события
- Любой сотрудник может добавлять и удалять события
- Это сделано для корпоративного использования

### Удалена изоляция по чатам

- Ранее события были изолированы по `chat_id`
- Теперь изоляция по авторизации пользователей
- События общие для всей команды

## 🐛 Troubleshooting

### Проблема: "Доступ запрещен"

**Решение:**
1. Проверьте `.env` — ваш ID должен быть в `ADMIN_TELEGRAM_IDS`
2. Перезапустите: `docker compose restart cinebot`
3. Напишите боту `/start`

### Проблема: Команды администратора не работают

**Решение:**
1. Проверьте роль: `/listemployees`
2. Убедитесь, что вы в списке администраторов
3. Проверьте логи: `docker compose logs cinebot --tail=50`
