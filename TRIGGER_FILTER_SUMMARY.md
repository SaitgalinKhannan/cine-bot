# Итоговая сводка: Фильтрация сообщений для LLM-агента

## ✅ Что реализовано

### 1. Фильтрация по триггерным словам
**Файлы изменены:**
- `app/handlers/llm.py` - добавлена проверка триггерных слов
- `app/config.py` - добавлена настройка `llm_trigger_words`
- `app/handlers/common.py` - обновлена справка `/help`
- `.env.example` - добавлена переменная `LLM_TRIGGER_WORDS`

**Как работает:**
- Бот проверяет каждое сообщение на наличие триггерных слов
- Если триггерное слово найдено → обрабатывает через LLM
- Если триггерного слова нет → игнорирует сообщение

**Триггерные слова по умолчанию:**
```
добавить, добавь, найти, найди, покажи, покажите,
удалить, удали, создать, создай, запланировать, запланируй,
искать, ищи, отменить, отмени, список, события
```

### 2. Работа в групповом чате БЕЗ упоминаний
**Важно:** Бот теперь работает в группе без необходимости упоминания!

**Примеры:**
```
✅ Добавь премьеру фильма Асия 25 марта
✅ Найди сценарий Горизонт
✅ Покажи ближайшие события
```

**Не нужно:**
```
❌ @BotName добавь премьеру...
```

### 3. Настраиваемые триггерные слова
**В `.env` можно настроить свой список:**
```env
LLM_TRIGGER_WORDS=добавить,найти,покажи,мой_триггер
```

### 4. Целевой групповой чат
**Если указан `GROUP_CHAT_ID`, бот работает только в этом чате:**
```env
GROUP_CHAT_ID=-1001234567890
```

## 🚀 Как протестировать

### 1. Дождитесь разрешения конфликта

**Текущая проблема:** Есть другой экземпляр бота (процесс 137572)

**Решение:**
```bash
# Найдите процесс
ps aux | grep "python.*app.main"

# Остановите его (требуется sudo)
sudo kill 137572

# Или подождите 2-3 минуты - Telegram автоматически отключит старый
```

### 2. Проверьте статус бота
```bash
docker compose logs cinebot --tail 20
```

**Ожидаемый результат:**
```
Bot started polling
```

**Без ошибок:** `TelegramConflictError`

### 3. Протестируйте в Telegram

**Тест 1: Обычное сообщение (должно игнорироваться)**
```
Привет, как дела?
```
Бот НЕ должен ответить.

**Тест 2: Сообщение с триггером (должно обработаться)**
```
Добавь премьеру фильма Асия 25 марта в 19:00
```
Бот должен ответить и добавить событие.

**Тест 3: Поиск файлов**
```
Найди сценарий Асия
```
Бот должен найти файлы.

**Тест 4: Просмотр событий**
```
Покажи ближайшие события
```
Бот должен показать список.

**Тест 5: В группе без упоминания**
```
Добавь встречу 30 марта в 15:00
```
Бот должен работать БЕЗ @упоминания.

## 🔧 Устранение проблем

### Бот не отвечает на сообщения

**Проверьте триггерные слова:**
```bash
docker compose logs cinebot | grep "No trigger words"
```

**Решение:** Используйте одно из триггерных слов (добавить, найти, покажи, удалить)

### Бот не работает в группе

**Проверьте GROUP_CHAT_ID:**
```bash
docker compose logs cinebot | grep "non-target group"
```

**Решение:** Убедитесь, что `GROUP_CHAT_ID` в `.env` совпадает с ID вашей группы.

### Telegram Conflict Error

**Проблема:** Другой экземпляр бота уже запущен.

**Решение:**
1. Найдите процесс: `ps aux | grep "python.*app.main"`
2. Остановите: `sudo kill <PID>`
3. Или подождите 2-3 минуты

### LLM-агент не работает

**Проверьте API ключ:**
```bash
docker compose logs cinebot | grep "LLM agent"
```

**Решение:** Убедитесь, что `OPENROUTER_API_KEY` указан в `.env`.
